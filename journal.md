# Reflective Journal

## September 16, 2026

This week I built the first version of my CART253 course website using Markdown and GitHub, and it's been a nice reintroduction to how much you can do with plain text. I'd used Markdown casually before, for quick notes, but I hadn't thought about it as a way to *build* something — a homepage, a structured document with headings, links, and images that renders into a real, browsable page through GitHub Pages. There's something satisfying about writing `## About This Website` and watching it instantly become a styled heading, no CSS required.

What surprised me most was how little friction there is between "writing" and "publishing." Editing a `.md` file, committing it, and pushing to GitHub is the entire deployment pipeline — no build step, no server to configure. That immediacy makes we want to keep adding to the site, rather than treating it as a one-time assignment.

The trickiest part was getting comfortable with relative paths for images — remembering that `images/banner.svg` is relative to wherever the Markdown file lives, and that GitHub's file browser and GitHub Pages don't always render things identically, so I had to double check both.

I hope the future audience for this site — classmates, instructors, maybe future employers — will see it as a genuine record of how my prototyping skills developed over the semester, not just a polished final product. My aspiration is to keep this repository alive and messy in a good way: full of small experiments, honest notes about what didn't work, and a clear trail of how each idea grew into the next.
